# WeatherApp4

Full-stack weather application built with:

## Backend

- Node.js
- Express
- MongoDB Atlas
- Mongoose
- bcrypt
- OpenWeather API

## Frontend

- Next.js
- React
- Tailwind CSS

## Features

- User registration
- User login
- Password hashing
- Add city
- Delete city
- Weather search
- MongoDB persistence

## Environment Variables

- Backend:

PORT= MONGODB_URI= OWM_API_KEY=

- Frontend:

NEXT_PUBLIC_API_URL=
